# Operations Control Panel Predecessor Archive

Retired: 2026-10-01

Preserves the legacy bank operations/control-panel interface.

## Original canonical family
/control-panel/

## Replacement
The approved Operations Console V2 has been promoted into /control-panel/.

## Preserved implementation
Legacy overview, accounts, KYC, KYC-data, profile-picture, site-users and transaction screens are archived with the predecessor control-panel header, desktop/tablet/mobile styles and JavaScript.

## Shared/data dependencies
The underlying /control-panel/app.php remains in service as a compatibility/core bootstrap used by the promoted V2 operations application layer. Database records are not duplicated; only the retired application implementation is archived.

## Legacy routes
Retired operational aliases redirect into the corresponding modern customer/KYC views.
