# Velmora Homepage V1 Archive

This folder preserves the homepage that was live immediately before the professional homepage was promoted to the root route.

Archived source:
- `index.php.txt` — previous root homepage PHP/HTML source.
- `home.css` — previous desktop homepage-specific stylesheet.
- `tab-home.css` — previous tablet homepage-specific stylesheet.
- `mobile-home.css` — previous mobile homepage-specific stylesheet.

The previous homepage also used shared site assets such as `common-sections/header.php`, `common-sections/footer.php`, and the global main stylesheets. Those shared files remain in their normal repository locations because other pages still use them.

Archived for reference only. These files are not the active homepage.
