# Customer Dashboard Predecessor Archive

Retired: 2026-10-01

Preserves the complete legacy customer-dashboard screen family that preceded Dashboard V3.

## Original canonical family
/dashboard/

## Replacement
The approved Dashboard V3 product has been promoted into /dashboard/.

## Preserved implementation
Legacy overview, account creation/management, transaction views, transfer workflow, profile, profile-picture, KYC, password and preference pages are archived together with the predecessor dashboard header, desktop/tablet/mobile CSS and dashboard JavaScript.

## Shared/data dependencies
The underlying /dashboard/app.php remains in service as a compatibility/core bootstrap used by the promoted V3 application layer. Database tables and uploaded user assets remain in place. User-generated uploads are intentionally not duplicated into documentation archives.

## Legacy routes
Former subroutes are redirected into the corresponding V3 screens so bookmarks do not reopen retired interfaces.
