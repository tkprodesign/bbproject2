# Velmora Digital Design System

This system is the visual foundation for the professional Velmora public site and the V3 banking workspace.

## Brand direction

Velmora should feel **structured, calm, premium and credible**. The interface should avoid loud gradients, oversized iconography, crowded information blocks and decorative elements that do not help the banking task.

## Core colors

- Deep Navy — `#0B2239`: primary banking/authority surface
- Navy Mid — `#103653`: secondary dark surface
- Ink — `#172536`: main body text
- Gold — `#E4AD43`: restrained brand accent and premium highlight
- Green — `#14805E`: verified/success states
- Soft Background — `#F4F6F8`: section/page background
- Border — `#E3E8ED`: low-contrast dividers
- White — `#FFFFFF`: primary card surface

Gold is an accent, not a background default. Green is reserved for successful/verified states.

## Typography

- Display / headings: **Manrope**
- UI / body: **Inter**
- Large headings use tight tracking and moderate line height.
- Body copy remains small-to-medium, calm and readable.
- Uppercase micro-labels are used sparingly for banking hierarchy.

## Spacing

Base rhythm: 4px. Common steps: 8, 12, 16, 24, 32, 48, 64, 92.

Public marketing sections should use generous vertical spacing. Dashboard surfaces should be denser but never cramped.

## Shape language

- Controls: 8–10px radius
- Cards: 14–18px radius
- Feature/hero surfaces: up to 24px radius
- Pills only for compact statuses, currencies and metadata

## Elevation

Use borders first. Shadows should be soft and low contrast. Strong shadows are reserved for floating panels, dropdowns and hero-level content.

## Component rules

Buttons:
- Primary = navy background
- Secondary = white with neutral border
- Gold = high-value CTA only
- Never use multiple competing primary actions in the same small area

Cards:
- One visual purpose per card
- Title, concise explanation, single action
- Avoid excessive icons and decorative backgrounds

Navigation:
- Public site: white navigation with clear sign-in/open-account actions
- Banking workspace: dark navy sidebar with white active state

Status:
- Success/verified = green
- Pending/review = amber
- Failed/rejected = red
- Neutral/posted = blue-gray

## Photography

Prefer credible real-world banking/business/lifestyle photography with neutral color treatment. Avoid generic crypto imagery, exaggerated wealth imagery or overly staged corporate stock photos.

## Content voice

Professional, concise and operational. The interface should explain what will happen next. Avoid hype, superlatives and vague claims.

## Banking interaction principle

The interface must represent financial actions truthfully. Changing a visual control must not imply that money moved when it did not. FX uses quote → review → confirmation. Transfers use preparation → review → submission/status. Balances remain attached to account currencies.
